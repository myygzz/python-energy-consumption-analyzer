Python Energy Consumption Analyzer

A beginner-friendly Python project that analyzes daily electricity consumption data and visualizes energy usage using Matplotlib.

This project combines my academic background in Renewable Energy with my current studies in Internet of Things (IoT) Engineering.

🎯 Project Objectives

- Read electricity consumption data from a CSV file.
- Calculate total energy consumption.
- Calculate average daily energy consumption.
- Identify the day with the highest electricity usage.
- Generate a visualization of daily energy consumption.

🛠️ Technologies Used

Technology| Purpose
Python| Main programming language
CSV| Data storage and reading
Matplotlib| Data visualization

🚀 How to Run

1. Clone the repository

git clone (https://github.com/myygzz/python-energy-consumption-analyzer)

2. Navigate to the project directory

cd python-energy-consumption-analyzer

3. Install Matplotlib

pip install matplotlib

4. Run the program

python main.py
